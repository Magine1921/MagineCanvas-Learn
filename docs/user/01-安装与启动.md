# MagineCanvas Learn 0.2.2 安装与启动

本文适用于学习版 Windows 客户端。源码用户还应阅读 `06-源码运行与打包.md`。

## 1. 安装包与目录版

0.2.2 安装包文件名为：

```text
MagineCanvas-Learn-Setup-0.2.2.exe
```

双击安装并按向导选择目录。免安装目录版入口为：

```text
win-unpacked\MagineCanvas-Learn.exe
```

请只从项目官方发布页或项目所有者提供的渠道获取安装包，并在下载后核对发布说明中的校验信息。

## 2. 学习版功能范围

学习版源码及客户端均不包含 3D 摄像机、3D 导演台和一键成片。需要完整功能可访问[正式版网页试用版](https://magine-trial.magine1921.workers.dev/)。

## 3. Windows 安装注意事项

- 建议安装到英文路径或常规用户目录。
- 第一次打开时，如系统弹出防火墙提示，请只允许所需网络范围。
- 若安全软件拦截，请先核对安装包来源和校验信息，再决定是否放行。
- 不要把安装目录内部文件单独移动，也不要随意清理应用数据目录。

通常不需要管理员权限。仅在确认是目录权限问题时，再尝试以管理员身份运行安装程序。

## 4. 首次启动与配置

首次打开后：

1. 在欢迎页新建或打开工程。
2. 进入「API 配置」。
3. 选择需要使用的模型分类。
4. 填写用户自己的 API Key、服务地址或本地模型路径。
5. 保存后创建最小测试节点，确认配置有效。

API 配置请查看 `02-API配置教程.md`。第三方 API 可能收费，密钥和账号由用户自行管理。

## 5. 打开软件后没有反应

依次检查：

1. 完全退出已有的 MagineCanvas Learn 进程后重新打开。
2. 检查安全软件是否隔离了程序文件。
3. 使用英文路径重新安装。
4. 运行 `win-unpacked\MagineCanvas-Learn.exe`，判断是否仅安装器异常。
5. 保留错误截图和日志，但分享前删除 API Key、账号信息和本地绝对路径。

## 6. 数据保存与备份

MagineCanvas Learn 会在本机保存工程、配置和部分缓存。清理应用数据可能导致：

- API 配置丢失；
- 历史生成素材不可访问；
- 本地语音模型需要重新下载或初始化；
- 工程缓存失效。

移动到另一台电脑时，请使用应用提供的工程保存或导出能力，并确认工程所需素材已包含；不要仅复制缓存目录。
