# Magine Canvas 快速开始

Magine Canvas 是一个 AI 工作流画布工具。你可以在画布上添加素材、图片生成、视频生成、音乐/语音、画质增强、720 全景和 Agent 节点，再通过连线把素材和提示词传递给生成节点。

## 1. 第一次使用

1. 打开 Magine Canvas。
2. 点击右上角「API 配置」。
3. 至少配置一个可用的图片或视频 API。
4. 回到首页，点击「新建画布」。
5. 添加一个图片生成节点或视频生成节点。
6. 输入提示词。
7. 点击发送按钮开始生成。

## 2. 最简单的图片生成流程

1. 新建画布。
2. 添加「图像生成」节点。
3. 点击节点，下方会展开编辑面板。
4. 输入提示词，例如：

```text
一只小猫坐在窗边，柔和阳光，电影感，高清细节
```

5. 选择图片比例、分辨率和模型。
6. 点击发送按钮。
7. 等待生成完成。

生成成功后，图片会显示在节点上。如果同一个节点生成多张图片，历史图片会显示在节点下方，点击缩略图可以切换查看。

## 3. 最简单的视频生成流程

1. 添加「视频生成」节点。
2. 输入提示词，例如：

```text
一只小猫在客厅里追逐光斑，镜头缓慢推进，温暖自然光
```

3. 选择视频比例、分辨率、时长和模型。
4. 点击发送按钮。
5. 等待生成完成。

生成成功后，视频会显示在节点上。点击视频上的播放按钮即可播放。

## 4. 用图片作为参考生成视频

1. 添加「素材」节点并上传图片。
2. 添加「视频生成」节点。
3. 从素材节点连接到视频生成节点。
4. 点击视频生成节点，确认素材缩略图出现在编辑面板上方。
5. 输入动作描述。
6. 选择支持图片输入的视频模型。
7. 点击发送。

如果模型不支持图片输入，参考图不会生效。

## 5. 常用按钮说明

| 按钮 | 作用 |
|---|---|
| 发送 | 开始生成任务 |
| 停止 | 取消当前任务 |
| 下载 | 下载当前生成结果 |
| 自由截帧 | 在视频上手动选择画面并截取为新素材 |
| 一键首帧 | 截取视频第一帧为新素材 |
| 一键尾帧 | 截取视频最后一帧为新素材 |

## 6. 生成失败时先看哪里

1. 看节点上的红色错误提示。
2. 看 API 配置是否正确。
3. 看服务商账号是否有余额。
4. 换一个简单提示词测试。
5. 换模型测试。

如果错误和 Kie、即梦、Topaz、TTS 有关，可以继续查看 `05-常见问题.md`。
