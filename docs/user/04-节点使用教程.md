# 节点使用教程

这份文档介绍常用节点的使用方法。

## 1. 素材节点

素材节点用于放入图片、视频或其他参考素材。

常见用途：

- 上传图片作为参考图。
- 接收其他节点生成的图片或视频。
- 在提示词中通过 `@` 引用素材。

使用建议：

- 图片建议使用 JPG 或 PNG。
- 视频建议使用常见 MP4 格式。
- 如果素材无法被下游节点识别，重新上传或保存项目后再试。

## 2. 图像生成节点

用于文字生图或参考图生图。

使用步骤：

1. 添加图像生成节点。
2. 点击节点展开编辑面板。
3. 输入提示词。
4. 选择比例、分辨率和模型。
5. 点击发送按钮。

历史图片会显示在节点下方，点击缩略图可以切换。

## 3. 视频生成节点

用于文字生视频或图片参考生视频。

使用步骤：

1. 添加视频生成节点。
2. 如需参考图，把素材节点连接到视频节点。
3. 输入视频描述。
4. 选择比例、分辨率、时长和模型。
5. 点击发送按钮。

生成成功后，可以直接在节点上播放视频。

视频节点还支持：

- 自由截帧
- 一键首帧
- 一键尾帧
- 下载视频
- 历史视频切换

## 4. 音乐/语音节点

用于生成音乐或语音。

使用步骤：

1. 添加音乐/语音节点。
2. 选择音乐或语音模式。
3. 输入描述。
4. 选择模型和时长。
5. 点击生成。

生成成功后，节点上会出现播放按钮和波形 UI。

## 5. 画质增强节点

用于提升图片或视频质量。

使用步骤：

1. 把素材连接到画质增强节点。
2. 选择图片或视频模式。
3. 选择放大倍数。
4. 点击生成。

注意：画质增强依赖 Kie 云端 Topaz 服务，云端任务失败时需要稍后重试或换素材。

## 6. 720 全景节点

用于生成或查看全景图。

使用方式：

- 标准模式：查看已有全景图。
- 智能体自动全景：根据输入图和提示词生成全景图。

如果使用参考图，请选择支持图生图的图片模型。

## 7. Agent 节点

Agent 节点用于文本推理、任务规划和工具调用。

使用步骤：

1. 添加 Agent 节点。
2. 选择 LLM 路由和模型。
3. 输入问题或任务。
4. 点击发送。

如果模型无响应，先在 API 配置里检查 LLM Key 和余额。

## 8. AI 助手

AI 助手可以用于：

- 问答
- 画布操作辅助
- 搜索整理
- 语音交互
- 工具调用

如果语音助手没有回应，先确认：

- 麦克风权限正常。
- 本地 STT 初始化完成。
- LLM 可用。
- TTS 有额度。
