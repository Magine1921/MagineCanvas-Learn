# 画布基础操作

Magine Canvas 的核心是无限画布。你可以在画布上添加不同节点，用连线把素材、提示词和生成结果串起来。

## 1. 新建画布

打开软件后，点击「新建画布」进入编辑界面。

## 2. 添加节点

常见节点：

- 素材节点
- 图像生成节点
- 视频生成节点
- 音乐/语音节点
- 画质增强节点
- 720 全景节点
- Agent 节点

你可以通过左侧工具栏或画布菜单添加节点。

## 3. 移动画布

常见操作：

- 鼠标拖拽空白处移动画布。
- 滚轮缩放画布。
- 使用底部缩放按钮调整视角。

## 4. 连接节点

节点左右两侧有连接点。

操作方式：

1. 从一个节点的输出点拖出连线。
2. 连接到另一个节点的输入点。
3. 下游节点会接收上游素材或内容。

例如：

```text
素材节点 -> 视频生成节点
图像生成节点 -> 视频生成节点
视频生成节点 -> 素材节点
```

## 5. 展开编辑面板

点击生成类节点后，下方会展开编辑面板。你可以在编辑面板里输入提示词、选择模型、调整比例、分辨率、时长等参数。

点击画布其他区域，编辑面板会收起。

## 6. 素材引用

在提示词输入框中可以使用 `@` 引用素材。

使用方式：

1. 输入 `@`。
2. 选择素材。
3. 素材会以标签形式插入提示词。

引用素材后，模型会尽量把该素材作为参考。

## 7. 历史素材

同一个生成节点多次生成时，历史结果会显示在节点下方。

你可以：

- 点击历史图片切换当前显示结果。
- 点击历史视频切换当前播放视频。
- 下载当前结果。

## 8. 保存项目

建议每次生成重要内容后保存项目，避免缓存或历史记录丢失。
